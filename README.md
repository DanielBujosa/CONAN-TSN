## README

**Repository Status: Private (Submission-Only Version)**

This repository contains the preliminary, non-public version of the tools developed exclusively for participation in the **ECRTS 2025 Industry Challenge**. At this stage, the repository is private and includes only the environment and scripts strictly necessary to reproduce the results submitted with our paper.

### Requirements and Usage

The current setup requires **MATLAB**. To reproduce the experiments, simply execute the provided `.bat` script from within the working directory. This script initializes the environment and launches the configured evaluation pipeline used in our submission.

### Public Release Plan

If the paper is accepted, we intend to release a fully configurable and user-friendly version of these tools to the public. This release will be made available on this repository either:

- by the time of the **conference presentation**, or  
- at the **camera-ready submission deadline** if requested.

The public release will include documentation, examples, and parameterization options to facilitate use by the wider research and industrial community.

For any questions or to request early access for review purposes, please contact the corresponding authors.
